## GitHub Pages

Для публикации перейдите в **Settings → Pages → Build and deployment**, выберите **Deploy from a branch**, ветку **main**, папку **/(root)** и нажмите **Save**. После публикации страницы будут доступны по ссылкам выше.

## Важно

Это **неофициальные макеты**, а не сайты самих стоматологий. Услуги и сведения требуют проверки владельцами, цены и врачи не выдуманы. Фото подключены из общедоступных ссылок Яндекс Карт и могут перестать загружаться при изменении адресов, политики доступа или удаления оригиналов. Перед коммерческим использованием необходимо согласовать права на изображения и контент.
