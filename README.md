## GitHub Pages

Для публикации перейдите в **Settings → Pages → Build and deployment**, выберите **Deploy from a branch**, ветку **main**, папку **/(root)** и нажмите **Save**. После публикации страницы будут доступны по ссылкам выше.

## Важно

Это **неофициальные макеты**, а не сайты самих стоматологий. Услуги и сведения требуют проверки владельцами, цены и врачи не выдуманы. Фото подключены из общедоступных ссылок Яндекс Карт и могут перестать загружаться при изменении адресов, политики доступа или удаления оригиналов. Перед коммерческим использованием необходимо согласовать права на изображения и контент.

## Постоянный стандарт сайтов

Для всех следующих проектов в этом репозитории обязательны:

- интерактивная **3D-модель зуба** в первом экране стоматологических сайтов (с разбором на слои, вращением и приближением);
- фирменная палитра конкретной клиники, реальные фото и адаптивная вёрстка;
- каталог услуг, рабочие контакты, галерея и функциональные кнопки;
- **отзывы и рейтинг Яндекс Карт только при наличии подтверждённых данных**, без вымышленных рейтингов;
- перепроверка всех исходных данных.

Прочитать перед новым макетом: [AGENTS.md](AGENTS.md) и [SITE_STANDARD.md](SITE_STANDARD.md). Общий модуль 3D: [assets/tooth-3d.js](assets/tooth-3d.js).

**АльмаКлиник:** без блока Яндекс-отзывов, поскольку наличие рейтинга Яндекса не подтверждено. **Арована:** с блоком отзывов Яндекса; цифры из сторонней выборки датированы и не выдаются за живые.

**МиксДент:** Яндекс Карты показывают рейтинг 4,6, 21 оценку и 14 текстовых отзывов (просмотр карточки 10.11.2026; данные могут измениться). Интерфейс и 3D-модель используют общие `assets/`. Галерея содержит ссылки на все 66 фото из переданного пользователем архива; хранение изображений у Яндекса не гарантирует бессрочную доступность. Для стабильного коммерческого сайта согласуйте права и разместите фото на собственном хостинге.
